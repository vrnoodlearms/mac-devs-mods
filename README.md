# Mac Devs Mods

BONELAB code mods: God Man and Level Selector.

Website: https://vrnoodlearms.github.io/mac-devs-mods/

The complete website source, approved images, mod DLLs, and DLL-only ZIPs are in `Mac-Devs-Mods-Website.zip`. The Pages workflow extracts that source package, publishes the mod downloads as GitHub Releases, and builds the website. Download counts come from those release assets.

To update the website, extract the source ZIP, edit the files, and replace the source ZIP. Keep the directory structure inside the archive. New mod builds need a new version and release tag so existing download counts are preserved.

MapMenuPlus is by MafiaBossTeam, with map discovery and loading fixes by Mac Devs. God Man is a custom BoneMenu mod.
