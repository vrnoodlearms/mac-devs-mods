# Mac Devs Mods

BONELAB code mods: God Man and Level Selector.

Website: https://vrnoodlearms.github.io/mac-devs-mods/

## Hosting

The prebuilt `index.html` contains the website, styles, scripts, and approved pictures. GitHub Pages publishes directly from the `main` branch root using its standard publishing option. No paid hosting or custom build runner is required.

The editable source and mod files are in `Mac-Devs-Mods-Website.zip`. Extract it to work on the site. Mod downloads use GitHub Releases, and the website reads actual release asset download counts.

The optional custom publishing workflow is retained for future use. It is not required for branch-based publishing.
